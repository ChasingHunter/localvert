# Code of Conduct

This project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
by reference. The full text there is the actual policy; this file is a short
pointer to it.

In short: be respectful, assume good faith, and don't harass anyone. Behavior
that makes the project unwelcoming for others — including maintainers — isn't
acceptable, regardless of intent.

## Enforcement

To report a concern, contact the maintainer via a private message on GitHub
(**@ChasingHunter**). Reports are handled as discreetly as possible.

This is not the channel for security vulnerabilities — see
[SECURITY.md](SECURITY.md) for those.
